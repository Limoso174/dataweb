# 数据怎么定 · 给 A 的详细说明

> A 是四个人里看起来最轻松的，但**A 定错了，四个人全白干。**
> 这份文档讲三件事：一行数据长什么样、指标怎么定、Excel 怎么变成代码。

---

## 一、先理解"一行数据"是什么意思

我们的数据，**一行 = 某个渠道在某一天的汇总**。

就像一张 Excel 表：

| 日期 | 渠道 | 访问量 | 订单数 | 成交金额 |
| --- | --- | --- | --- | --- |
| 2024-03-01 | 自然搜索 | 1280 | 64 | 12800.50 |
| 2024-03-01 | 信息流 | 860 | 21 | 4200.00 |
| 2024-03-02 | 自然搜索 | 1340 | 71 | 14200.00 |

在代码里，这一行写成这样（放在 `data.js` 里）：

```javascript
{ date: '2024-03-01', channel: '自然搜索', visits: 1280, orders: 64, revenue: 12800.5, complete: true },
```

一一对应：

| Excel 列 | 代码里的名字 | 类型 | 说明 |
| --- | --- | --- | --- |
| 日期 | `date` | 文字 | **必须**是 `2024-03-01` 这种格式 |
| 渠道 | `channel` | 文字 | 没有就写 `null` |
| 访问量 | `visits` | 数字 | 不带引号、不带逗号 |
| 订单数 | `orders` | 数字 | 同上 |
| 成交金额 | `revenue` | 数字 | 单位元，没有就写 `null` |
| （不是 Excel 列） | `complete` | true/false | 这行数据完整不完整 |

**这就是"数据契约"。** 四个人（还有四个人的 AI）全部照这个来，谁都不许自己改名字。

## 二、为什么必须第 1 天就定下来

因为 AI 会**猜**。

你对 AI 说"帮我做一个显示访问量的卡片"，它看你的代码里没有明确定义，就自己编一个字段名，比如 `pageViews`。
另一个人对 AI 说同一句话，AI 编出 `visit_count`。

两个人合起来，页面上一个显示数字、一个显示 `undefined`。**而且你们俩都不知道为什么。**

**定了契约之后，AI 只能在你给的框架里干活**，就不会乱编了。

### 定下来之后，别随便改

想加一个字段？可以，**但要在群里说一声**，并且告诉每个人"数据形状变了，你们拉一下最新代码"。

想改一个已有字段的名字或类型？**不要改。** 加一个新字段，旧的留着，等这一版做完再说。

## 三、指标怎么定（最容易糊弄的一步）

### 每个指标必须回答四个问题

| 问题 | 例子（好的） | 例子（坏的） |
| --- | --- | --- |
| 叫什么 | 转化率 | 效果 |
| 怎么算 | 订单数 ÷ 访问量 | （没说） |
| 什么范围 | 筛选范围内所有完整记录 | 全部 |
| 从哪来 | 表格里的 orders 和 visits 两列 | 系统里 |

### 好口径 vs 坏口径

**❌ 坏：** 「活跃用户数」

问题：什么叫活跃？今天来过算活跃，还是本周来过？访问一次算，还是停留 3 分钟算？没定义，两个人算出来的数能差一倍。

**✅ 好：** 「活跃用户数 = 当天有至少 1 次访问的去重用户。同一个人当天来了 5 次算 1 个。」

**❌ 坏：** 「平均客单价」

问题：是总金额除以订单数，还是每一单单独算再求平均？这两个答案不一样（尤其在有超大订单时）。

**✅ 好：** 「客单价 = 成交金额合计 ÷ 订单数合计。不含金额缺失的记录。」

### 三个特别容易错的指标

**1. 比率类（转化率、增长率）**

存的时候用小数（`0.0391`），显示的时候再乘 100 变成 `3.91%`。
**千万不要在数据里就存 3.91**，否则显示时会变成 `391%`——这是最常见的 bug。

**2. 平均值**

平均值不能用"把每天的转化率加起来除以天数"来算。
比如周一 100 访问 1 单（1%），周二 1 访问 1 单（100%），平均是 50.5%，但实际整体是 2/101 = 1.98%。

**正确的做法是：先把分子加起来，再把分母加起来，最后相除。**

**3. 有缺失值的指标**

某天金额缺失，那天该不该算进"总金额"？

我们采用的做法：**`complete: false` 的记录整行不参与指标计算**，但在明细表里显示出来，标上"已排除"。
页面顶部会提示"有 N 条记录被排除"。

**这样别人问"为什么我的数和你的不一样"，你能答上来。**

### 指标数量：3 到 5 个，不要超过 5 个

新手最常见的错误是列 12 个指标，结果每个都粗糙。
**3 个讲清楚的指标，比 12 个讲不清楚的强得多。**

## 四、把 Excel 变成代码（详细步骤）

假设你的 Excel 长这样，放在 `Sheet1`，数据从第 2 行开始：

| | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| **1** | 日期 | 渠道 | 访问量 | 订单数 | 成交金额 |
| **2** | 2024-03-01 | 自然搜索 | 1280 | 64 | 12800.5 |
| **3** | 2024-03-01 | 信息流 | 860 | 21 | 4200 |
| **4** | 2024-03-02 | 自然搜索 | 1340 | 71 | 14200 |

### 第 1 步：在 F2 单元格粘这个公式

```
="{ date: '"&TEXT(A2,"yyyy-mm-dd")&"', channel: '"&B2&"', visits: "&C2&", orders: "&D2&", revenue: "&E2&", complete: true },"
```

> ⚠️ 公式里的引号必须**全是英文引号** `"`，不能是中文引号 `"` `"`。
> 复制粘贴时如果被自动改成了中文引号，删掉重打一次。

### 第 2 步：往下拉，填满所有行

选中 F2，双击右下角的小方块（填充柄），自动填到数据最后一行。

F 列现在会变成这样：

```
{ date: '2024-03-01', channel: '自然搜索', visits: 1280, orders: 64, revenue: 12800.5, complete: true },
{ date: '2024-03-01', channel: '信息流', visits: 860, orders: 21, revenue: 4200, complete: true },
{ date: '2024-03-02', channel: '自然搜索', visits: 1340, orders: 71, revenue: 14200, complete: true },
```

### 第 3 步：复制 F 列，粘到 `data.js` 里

打开 `data.js`，找到 `records: [` 那一行，把光标放到方括号里面，粘贴。

粘完长这样：

```javascript
  records: [
    { date: '2024-03-01', channel: '自然搜索', visits: 1280, orders: 64, revenue: 12800.5, complete: true },
    { date: '2024-03-01', channel: '信息流', visits: 860, orders: 21, revenue: 4200, complete: true },
    { date: '2024-03-02', channel: '自然搜索', visits: 1340, orders: 71, revenue: 14200, complete: true },
  ]
```

**最后一行末尾那个逗号可以留着**，JavaScript 允许，不用特意删。

### 第 4 步：刷新页面检查

按 `F5`。如果页面上出现了数字，说明格式对了。
如果页面白屏，按 `F12` 看 Console 的红字——99% 是**引号或逗号**的问题。

## 五、Excel 里有空单元格怎么办

上面那个简单公式，遇到空单元格会生成 `revenue: ,` 这种坏代码，页面就白屏了。

**用这个带判断的版本，能自动处理空值：**

```
="{ date: '"&TEXT(A2,"yyyy-mm-dd")&"', channel: '"&IF(B2="","未知",B2)&"', visits: "&N(C2)&", orders: "&N(D2)&", revenue: "&IF(E2="","null",E2)&", complete: "&IF(OR(A2="",C2="",D2=""),"false","true")&" },"
```

它做了三件事：

- 渠道空了 → 写 `'未知'`
- 金额空了 → 写 `null`（不是 0，因为"没有这个数"和"金额是 0"不一样）
- 日期、访问量、订单数任一为空 → 标成 `complete: false`（这行不参与计算）

> `N()` 的作用是把空单元格变成 0，把文字数字变成真数字。

### 还有两个坑

**坑 1：数字里带逗号。**
如果 C 列显示的是 `1,280`（带千分位），粘出来会变成 `visits: 1,280`，这是坏的。
解决：把 C 列格式设成"数值、不用千分位"，或者用 `N(C2)`。

**坑 2：日期被 Excel 存成了数字。**
如果 A 列显示 `45352` 这种数字，说明格式不对。
解决：`TEXT(A2,"yyyy-mm-dd")` 会强制转成日期文字，一般能解决。还不行就把整列设为"短日期"格式。

## 六、假数据必须包含这五种脏情况

**这是第 1 天就要做的事，不是第 5 天。**

新手做的页面，永远只处理了"数据正常、有一百条"这一种情况。真实数据里一定会有下面这些，**任一条没处理，页面就白屏或显示 `NaN`**：

| 脏在哪 | 在我们的数据里长什么样 | 不处理的现象 |
| --- | --- | --- |
| **1. 空的** | `records: []` | 空白页，或者报错 |
| **2. 缺字段** | `channel: null`、`revenue: null` | 显示 `undefined`、`null` |
| **3. 数字写成文字** | `visits: "980"`（带引号） | 算出来是 `"980"+"860"` = `"980860"` |
| **4. 特别大的数** | `revenue: 99999999` | 撑破卡片，页面错位 |
| **5. 格式不统一** | `"2024-3-5"`、`"2024/03/09"` | 排序乱、筛选漏数据 |

`起步模板/data.js` 里的假数据**故意把这五种都放进去了**，你可以照着它的写法。

### 怎么自己测这五种

1. 把 `records: [` 后面的内容**全删掉**，改成 `[]` → 刷新，应该显示"暂无数据"
2. 把某一条的 `revenue: 4200` 改成 `revenue: null` → 刷新，金额应该不显示 `null`
3. 把某一条的 `visits: 1280` 改成 `visits: "1280"` → 刷新，数字应该还是一样
4. 把某一条的 `revenue` 改成 `99999999` → 刷新，卡片不该被撑破
5. 把某一条的 `date` 改成 `'2024/3/1'` → 刷新，应该还能正常显示

**五条都过了，你的数据处理才算能上真实数据。**

## 七、格式约定（全组统一，只定一次）

| 东西 | 约定 | 例子 |
| --- | --- | --- |
| 日期 | `YYYY-MM-DD`，两位补零 | `2024-03-05` |
| 时间范围 | 北京时间自然日 | 数据延迟 1 天 |
| 金额 | 单位：元，含税，显示 2 位小数 | `12800.50` |
| 百分比 | **存小数**，显示时乘 100 | 存 `0.0391`，显示 `3.91%` |
| 计数 | 整数，不带小数 | `1280` |
| 缺失值 | 数字缺失用 `null`，**不要用 0** | `revenue: null` |

**「缺失用 null 不用 0」这条特别重要。**
金额 0 元和一单都没成交是两件不同的事。如果都写 0，"平均客单价"会被拉低，而且没人能发现。

## 八、数据从哪来（三种常见情况）

**情况一：老师/公司给了一个 Excel**

最省事。直接用第四节的公式转换，**注意先看一眼有没有空单元格和格式不统一的行**。

**情况二：网上找的公开数据**

注意三件事：
- 数据量别太大。手写 JSON 超过 500 行你就会想放弃，**截取一个有代表性的时间段就够**
- 检查日期格式（很多是 `2024/3/5` 或 `03/05/2024`）
- 检查单位（金额可能是"万元"或"美元"）

**情况三：自己统计（问卷、手工记录）**

最可靠，因为你知道每一列是什么意思。
**注意：统计口径要在做问卷之前就定好，不然收上来的数据对不上。**

## 九、A 的每日检查清单

每天上传之前，A 自查这五条：

- [ ] 我改的只有 `data.js` 这一个文件
- [ ] 页面上每个数字，我都能用 Excel 手算出来对得上
- [ ] 数据里有空值/缺失吗？处理了没？
- [ ] 我没有改字段的名字（`date`、`visits` 这些）
- [ ] 刷新页面后，没有出现 `NaN`、`undefined`、`null`

**第 2 条最重要。** 页面上显示 14560，你就要能拿 Excel 算出来也是 14560。算不出来，说明中间某一步错了。
