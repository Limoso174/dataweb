# 起步模板 · 你们项目的起点

**双击 `index.html` 就能看到页面。** 不用装任何东西，不用运行任何命令。

这个模板是一个**已经做完的完整小例子**。你们要做的不是从零开始，而是**把它里面的数字和文字换成自己的**。

---

## 一、四个文件分别是什么

| 文件 | 归谁 | 里面有什么 |
| --- | --- | --- |
| `index.html` | **B** | 页面结构：标题区、筛选条、卡片区、图表区、表格区、页脚 |
| `style.css` | **C** | 全部样式，配色都在最上面的 `:root` 里 |
| `data.js` | **A** | 假数据 + 计算函数 |
| `app.js` | **D** | 格式化、画卡片、画图、画表格、三种状态、事件 |

**这四个文件必须在同一个文件夹里，名字不能改。**

---

## 二、现在这个页面上有什么

打开后你会看到：

- 顶部：标题、数据来源、更新时间
- 一条筛选栏：时间范围、渠道
- 五张指标卡：总访问量、订单数、成交金额、转化率、客单价
- 一张"每日访问量"柱状图
- 一张明细表（13 行）
- 页脚：指标口径说明

**还有两个藏起来的东西，试试看：**

- 点右上角 **"模拟请求失败"** → 看到出错状态和重试按钮
- 把时间范围选 **"仅最新一天"**，渠道选 **"私域"** → 看到空状态

## 三、每类人从哪开始改

### A（数据）—— 改 `data.js`

1. 打开 `data.js`，最上面那个 `window.DATA` 就是数据。
2. 用你的真实数据替换 `records` 数组里的内容。**怎么从 Excel 转过来，看 [`../03-数据怎么定.md`](../03-数据怎么定.md)。**
3. 如果你的指标不一样（比如没有"客单价"，要加"退款率"），改下面 `computeMetrics` 函数。

**注意事项：**

- 保持字段名不变：`date`、`channel`、`visits`、`orders`、`revenue`、`complete`
- **不要把假数据全部删掉换成干净的**。故意留几条脏的（空渠道、缺金额、超长数字），用来测页面。
- 改完刷新，页面上数字应该变了。**用 Excel 手算一遍对一下。**

### B（页面结构）—— 改 `index.html`

1. 改标题：找到 `<h1>` 那行。
2. 改文案：卡片是 `app.js` 生成的，但区块标题、说明文字在这里。
3. 改页脚的指标口径——**这块一定要写，不能空着。**
4. 要加新区块（比如再加一张表），在 `<main>` 里那个"预留"注释的位置加：

```html
<section class="panel">
  <h2>你要加的区块标题</h2>
  <div id="新容器名"></div>
</section>
```

加完告诉 D："我在 `index.html` 加了一个 `id="新容器名"` 的容器，你往里填东西。"

### C（样式）—— 改 `style.css`

1. 改配色：最上面的 `:root` 里改色号，改一次全站生效。
2. 改字号间距：找对应的选择器。
3. **改完把窗口拉窄到手机宽度看一遍**，确认没有横向滚动条。

**别在 `index.html` 里写 `style="..."`**，所有样式都放这个文件。

### D（交互）—— 改 `app.js`

1. 改指标卡：找 `renderCards` 函数，加一张卡就加一行。
2. 改图表：找 `renderChart`，现在是按日期画柱状图。
3. 改三种状态：找 `render` 函数开头的几行。
4. 接真实数据：把 `load()` 里的 `setTimeout` 换成真的 `fetch`。

**这是四个文件里最难的，其他人做完自己的要去帮 D。**

## 四、这个模板故意留的"坑"（别修掉）

`data.js` 里的假数据包含五种脏数据，**它们不是错误，是测试用例**：

| 在哪一行 | 脏在哪 |
| --- | --- |
| `channel: null` | 渠道缺失 |
| `visits: '980'` | 数字写成了文字 |
| `date: '2024-3-5'` | 日期没补零 |
| `date: '2024/03/09'` | 日期用了斜杠 |
| `revenue: 99999999` | 特别大的数 |
| `revenue: null` + `complete: false` | 不完整记录 |

页面上能正确处理它们（显示"未知渠道"、不显示 `NaN`、不撑破布局、明细表里标"已排除"）——**这就是你们代码要达到的标准。**

---

## 五、已知的"故意没做"

这个模板不是一个完整的产品，下面这些是故意留着让你们自己加的：

- 没有排序和分页（明细表 13 行不需要，几百行就需要了）
- 没有"导出 Excel"
- 没有第二页、没有路由
- 没有真实接口（`setTimeout` 假装在联网）
- 只有一个图表

---

## 六、换成你们的内容之后

改完记得：

1. 双击 `index.html` 确认能打开
2. 按 `F12` 确认 Console 没有红字
3. 提交、推送
4. 去网站上看一眼（等 1–2 分钟，`Ctrl + F5` 强制刷新）
